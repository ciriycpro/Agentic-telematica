## О чём кейс

Текущий телематический сервис оператора — учётная система: данные собираются
исправно, но между событием («слив топлива», «сирота-задача») и реакцией стоит
человек и часто — сутки. Между тем 10 500 компаний-абонентов оператора уже платят
за телематику, у оператора уже есть агентная платформа, компактная LLM в своём
контуре и голосовой канал.

Предложение: превратить платформу из учётной в **решающую** — она сама
классифицирует события, действует в пределах строго заданных полномочий и зовёт
человека там, где не имеет права или не уверена. Продаётся как надбавка к
действующему тарифу; строится один раз как общий мультитенантный контур.

## Пять принципов архитектуры

1. **Детерминизм на потоке.** Поток координат и телеметрии считают жёсткие
   правила; LLM-инференс на нём не сжигается — это вопрос себестоимости.
2. **LLM решает только на событиях и только из меню.** Выбор строго из белого
   списка действий; недоступный инструмент отсутствует у агента физически,
   а не «запрещён промптом».
3. **Матрица полномочий с измеримыми порогами доверия.** Автономия открывается
   классу действий по накопленной статистике (80% внутренние / 95% +
   подтверждающий вопрос — контакты с человеком), а не по календарю.
4. **LBS никогда не порождает автодействий.** Координата ±1 км — датчик низкого
   разрешения, а не доказательство: ложные претензии к людям исключены классом,
   а не настройкой.
5. **Канал апелляции.** Сотрудник оспаривает любое действие автоматики с любого
   телефона; спорный инцидент блокирует дальнейшие автодействия до
   человека-арбитра.

## Экономика

**Заказчик (300 сотрудников, 100 машин):**

| Показатель | Значение |
|---|---|
| Эффект (время диспетчера + топливо + SLA) | ~1,5 млн ₽/год |
| Цена тарифа «+решения» | 780 тыс. ₽/год |
| **Отдача** | **+30…+92%** (потенциал роста до +346% — не подтверждён, в базу не входит) |
| **Окупаемость** | **6–7 месяцев** |

**Оператор (единый мультитенантный контур):**

- Операционная безубыточность: **32 компании (0,3% базы)**
- План с целевой прибылью: **65 компаний (0,6% базы)**
- Разовые вложения: ~4,8 млн ₽, возврат за 24 месяца

Полный расчёт с формулами, чувствительностью и стресс-тестом — в
[`docs/full.md`](docs/full.md), раздел 5.

## Статус

- Три внешних ревью пройдены (продакт, коммерция, ИИ-архитектор)
- Решение выверено против 40+ рыночных систем: архитектурное ядро совпадает с
  практикой лидеров, автономия по измеримым порогам доверия — без аналогов
