# Agentic Telematica · prototype

Демо-стенд агентной диспетчеризации разъездных сотрудников поверх легаси-телематики
мобильного оператора. Реплей рабочего дня, воронка CEP, оркестрация трёх агентов
(инциденты, диспетчеризация, аналитик), панель владельца с метриками «теста
зеркала», живой чат с аналитиком через LLM.

**Живая версия:** [ciriycpro.online/AI-telematica-demo](https://ciriycpro.online/AI-telematica-demo/)

Стек: React 18 + Vite 5, никаких внешних UI-библиотек. Один компонент
(`src/App.jsx`, ~800 строк), production-сборка — статика (`~64 КБ gzip`).

---

## Запуск локально

Требования: Node.js 18+, npm.

```bash
npm install
npm run dev          # http://localhost:5173 — hot reload
npm run build        # dist/ — статическая сборка
npm run preview      # http://localhost:4173 — проверить сборку
```

## Как устроен чат аналитика

По умолчанию аналитик стучится в **OpenRouter → Claude Haiku 4.5** (ключ вшит в
клиент как есть — стенд демонстрационный, лимит 5 вопросов на сессию через
`localStorage`).

Если планируете форк / приватное развёртывание — переключите провайдера в
`src/App.jsx` (метод `ask` внутри `DemoStand`), поменяйте `Authorization`
и (при желании) название модели. Для устойчивого прод-варианта — вынесите
ключ на сервер-прокси (Cloudflare Worker / Vercel Edge) и обращайтесь к
своему эндпоинту.

Системный промпт аналитика — там же в методе `ask`: пять правил ответа
(отвечать только по данным демо-дня, отказывать вне контекста стенда,
краткость, термины из документа, числа только из блока «метрики») + JSON-срез
демо-дня, который передаётся с каждым запросом.

## Кроссбраузерность

Сборка Vite делает две версии автоматически:
- **modern** — ES2015+ modules (Chrome 87+, Safari 12+, Firefox 78+, Edge 88+)
- **legacy** — SystemJS + core-js полифилы (для древних браузеров)

Браузер сам выбирает нужную через `<script type="module">` vs `<script nomodule>`.
На узких экранах (< 1024px) показывается заглушка с приглашением открыть на десктопе
и кнопкой «Показать всё равно».

## Деплой на GitHub Pages в подпапку

Если хотите повесить стенд по адресу вида `https://your-domain.com/my-demo/` —
раскомментируйте `base` в `vite.config.js` и пропишите ваш путь:

```js
export default defineConfig({
  base: '/my-demo/',
  // ...
})
```

После `npm run build` содержимое `dist/` можно класть в подпапку GitHub Pages
репозитория. Пример живой раскатки — этот стенд на `ciriycpro.online/AI-telematica-demo`
(отдельный репо-контейнер, не этот).
